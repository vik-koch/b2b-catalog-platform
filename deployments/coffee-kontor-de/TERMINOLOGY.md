# Terminology — German

For whoever translates or edits this deployment's text: one German word per
English term, so a customer meets the same name on the shelf, in the cart, in
the mail and on the PDF. The app does not read this file.

The shop addresses everyone as **Sie**. Quotation marks are „…“, and a number
goes before its unit with a space: `19 %`, `250 g`, `12,50 €`.

## Shop and catalogue

| English                            | German                                   | Note                                                |
| ---------------------------------- | ---------------------------------------- | --------------------------------------------------- |
| catalogue                          | Katalog                                  | the browsable tree; "our range" is _Sortiment_      |
| range                              | Sortiment                                |                                                     |
| product                            | Produkt                                  | never _Artikel_: the shop quotes no article numbers |
| category                           | Kategorie                                |                                                     |
| variant                            | Variante                                 |                                                     |
| set (sold as a set)                | Set                                      |                                                     |
| sold together (pairing)            | zusammen verkauft                        |                                                     |
| specifications                     | Merkmale                                 |                                                     |
| document                           | Dokument                                 |                                                     |
| in stock / few left / out of stock | vorrätig / nur noch wenige / ausverkauft |                                                     |
| piece · pack · box                 | Stück · Packung · Karton                 | short: Stk. · Pck. · Ktn.                           |
| price on request                   | Preis auf Anfrage                        |                                                     |
| VAT                                | MwSt.                                    | _inkl. 19 % MwSt._, _zzgl. 19 % MwSt._              |

## Accounts

| English                      | German                     | Note                                         |
| ---------------------------- | -------------------------- | -------------------------------------------- |
| customer                     | Kunde, Kundin              | never _Käufer_; plural-neutral: _Kundschaft_ |
| account                      | Konto, Kundenkonto         |                                              |
| sign in / log in             | anmelden                   | both English verbs                           |
| sign out / log out           | abmelden                   |                                              |
| register, request an account | Konto beantragen           | accounts are approved, not instant           |
| password                     | Passwort                   |                                              |
| sign-in code                 | Anmeldecode                |                                              |
| company ID                   | Unternehmenskennung        | its formats: USt-IdNr., Steuernummer         |
| private person / company     | Privatperson / Unternehmen |                                              |
| staff                        | Team, Mitarbeitende        |                                              |
| admin · manager · user       | Admin · Manager · Kunde    | the roles                                    |
| customer tier                | Kundengruppe               | staff only                                   |
| price list                   | Preisliste                 | staff only                                   |
